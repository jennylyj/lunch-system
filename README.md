# 🍱 訂餐系統 (含飲食規劃與金庫儲值管理)

這是一個專為團體訂餐設計的**簡潔俐落、手機直式優化**網頁訂餐系統。前端可直接免費發布至 **GitHub Pages**；後端連結 **Google 試算表 (Google Sheets)** 的 5 個工作表，支援日曆預約點餐、各天餐廳自動連動與團體金庫儲值金額管控！

---

## ✨ 5 大核心功能

1. **📅 日期切換與飲食規劃連動**：
   - 頂部提供【今天】、【明天】、【後天】與【日曆選擇器】快捷切換列。
   - 切換日期時，系統會自動讀取試算表中該日期所安排的「餐廳名稱」，並**自動顯示該餐廳專屬菜單**！成員可提前預約下單未來的餐點。
2. **👤 身份登入與購物車**：
   - 快速登入切換身份（儲存於瀏覽器 `localStorage`）。
   - 手機直式排版，各品項獨立 `+` / `-` 按鈕，支援一人點選多份與多種餐點。
   - 懸浮底部購物車列，即時計算總金額。
3. **📊 當日/預約便當統計 (雙切換模式)**：
   - **📦 依品項模式**：顯示這款便當有幾個人點（例如：`椒麻雞腿飯 x3 (小明, 小華, 老張)`）。
   - **👥 依人名模式**：顯示每個人點了什麼與小計金額（例如：`小明：椒麻雞腿飯 x1, 蘿蔔貢丸湯 x1 (小計 $175)`）。
   - **📋 一鍵複製文字明細**：按鈕自動格式化點餐內容，輕鬆複製貼到 LINE / Teams 點餐群組。
4. **💰 金庫與累積儲值管理**：
   - 專屬【累積儲值】紀錄，標示 `已收款` / `未收款` 狀態。
   - **現在餘額計算公式** = **`累積儲值 (僅採計已收款)`** - **`累積消費 (所有訂單總額)`**。
   - 成員可在前端點選「➕ 申請儲值」新增儲值紀錄，待管理員確認。
5. **💡 示範模式與 Google 試算表無縫串接**：
   - 內建台大醫學院「杏園美食」真實菜單與預設飲食規劃，未連線前即可順暢體驗！

## 📊 Google 試算表 5 大工作表結構

本系統串接 Google 試算表的 5 個工作表：

1. **`餐廳清單`**：`餐廳名稱` | `品項名稱` | `單價` | `分類` | `供應狀態` (ON/OFF)
2. **`raw紀錄`**：`送出時間` | `姓名` | `金額` | `點餐明細` | `日期` | `狀態`
3. **`金庫`**：`姓名` | `現在餘額` | `累積儲值錢` | `累積消費` | `最後更新時間`
4. **`累積儲值`** (NEW!)：`儲值時間` | `姓名` | `儲值金額` | `收款狀態` (已收款/未收款) | `備註`
5. **`飲食規劃`** (NEW!)：`日期` | `餐廳名稱` | `開放狀態` | `備註`

## 🚀 部署與更新 Apps Script 步驟

如果先前已部署舊版，請跟著以下步驟更新 Apps Script：

1. 開啟您的 Google 試算表 ➔ **【擴充功能】** ➔ **【Apps Script】**。
2. 將本專案中 `google-apps-script/Code.gs` 的內容**全選複製並覆蓋貼上**。
3. 按下 **💾 儲存**。
4. 在上方選擇 `setupSheets` 函式並點選 **【執行】**，系統將自動為您補充新增 **`累積儲值`** 與 **`飲食規劃`** 兩個工作表與範例資料！
5. 點選右側藍色 **【部署】** ➔ **【管理部署】** ➔ 點選筆頭圖示 ➔ 選擇 **【建立新版本】** ➔ 按下 **【部署】**。
6. 複製獲得的 Web App URL 貼回系統【⚙️ 後端設定】即可！
